# Changelog / 更新记录

## 1.0.0 — 2026-10-19

First owner-authorized public binary distribution of PortScope for Windows x64.

- Real local TCP/UDP, IPv4/IPv6 and process observation; occupancy lookup and full details.
- Evidence-based development project recognition with confidence and reasons.
- Local listener history, observation gaps, timelines and sampled trends.
- Independent quick watch/favorite actions, notes and identity-aware project workspaces.
- Five themes, five interface sizes, Chinese/English, versioned local JSON backup/restore.
- Optional limited Docker published mappings and running WSL inventory.
- Reviewed dependency notices/source availability and SHA-256 downloads; unsigned binaries.

Public assets reuse the exact final local 1.0.0 binaries. Two-hour testing is incomplete, not passed; other limits are documented. No application source is published and no project open-source license was selected.

中文：首次正式公开二进制分发，保留原1.0.0程序与校验值。主要功能为真实端口观察、项目证据识别、历史与关注收藏、工作区、主题缩放及备份恢复。Docker/WSL仅有限支持，未签名，长期和硬件限制如实列出，不公开自有源码。
